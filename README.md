# 🎓 Student Record System in C

A mini project developed in **C Programming Language** using the **Linked List Data Structure** to manage student records efficiently.

This project was created as a **Semester 2 Mini Project** for practical understanding of **Data Structures and Algorithms (DSA)** concepts.

---

## 🚀 Features

- ➕ Add Student Record  
- 📋 Display All Student Records  
- 🔍 Search Student by Roll Number  
- ❌ Delete Student Record  
- 📊 Sort Students by Marks  
- 🔤 Sort Students by Name  
- 📌 Menu Driven Interface
- 💾 Permanent data storage using students.txt

---

## 🧠 Concepts Used

- Linked List  
- Dynamic Memory Allocation  
- Structures in C  
- Functions  
- Sorting Techniques  
- String Handling  
- Pointer Concepts
